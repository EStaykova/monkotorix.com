# Balance Bridge Maths

Source code for the Balance Bridge Maths game.

## What is included
- React and TypeScript source under `src/`
- The puzzle generator and age/level journey logic
- Train, space, dinosaur and garden themes
- Profile, stations, level-ups and sticker book
- App Builder project configuration

## Important
This is the App Builder project source. The platform scaffold and dependencies are not included in this archive. To create an ordinary standalone website for other hosting, export or adapt the React source into a separate web project.

The latest profile/stations/stickers changes are included in this archive, even though they have not yet been published to the live app link.
